# 🌍 Global E-commerce Sales Data Analysis

## 📌 Project Overview

This project performs an end-to-end analysis of global e-commerce sales data to discover meaningful business insights related to sales, profit, customers, products, regions, discounts, shipping costs, and payment methods.

The project demonstrates a complete Data Analyst workflow starting from raw data cleaning and exploratory data analysis to SQL analysis, Excel reporting, and an interactive Power BI dashboard.

---

# 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Analyze total profit and profit margin
- Identify top-performing countries and regions
- Find the best-performing product categories
- Identify top-selling products
- Identify high-value customers
- Analyze customer segments
- Analyze payment methods
- Study monthly and yearly sales trends
- Analyze discounts and their impact on profit
- Identify loss-making products
- Analyze shipping costs
- Build an interactive Power BI dashboard
- Generate actionable business recommendations

---

# 📊 Dataset Information

The dataset contains **2,000 e-commerce transaction records** and **15 original columns**.

### Dataset Columns

| Column | Description |
|---|---|
| Order_ID | Unique order identifier |
| Order_Date | Date of order |
| Customer_Name | Name of customer |
| Customer_Segment | Customer segment |
| Country | Customer country |
| Region | Geographical region |
| Product_Category | Product category |
| Product_Name | Product name |
| Quantity | Quantity purchased |
| Unit_Price | Price per unit |
| Discount_Percent | Discount percentage |
| Total_Sales | Total sales amount |
| Shipping_Cost | Shipping cost |
| Profit | Profit generated |
| Payment_Method | Payment method |
