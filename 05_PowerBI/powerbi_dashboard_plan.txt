STEP 3 — CREATE DAX MEASURES
============================================================

Go to:

Modeling → New Measure


------------------------------------------------------------
1. Total Sales
------------------------------------------------------------

Total Sales =
SUM(SalesData[Total_Sales])


------------------------------------------------------------
2. Total Profit
------------------------------------------------------------

Total Profit =
SUM(SalesData[Profit])


------------------------------------------------------------
3. Total Quantity
------------------------------------------------------------

Total Quantity =
SUM(SalesData[Quantity])


------------------------------------------------------------
4. Total Orders
------------------------------------------------------------

Total Orders =
DISTINCTCOUNT(SalesData[Order_ID])


------------------------------------------------------------
5. Total Customers
------------------------------------------------------------

Total Customers =
DISTINCTCOUNT(SalesData[Customer_Name])


------------------------------------------------------------
6. Total Products
------------------------------------------------------------

Total Products =
DISTINCTCOUNT(SalesData[Product_Name])


------------------------------------------------------------
7. Average Order Value
------------------------------------------------------------

Average Order Value =
DIVIDE(
    [Total Sales],
    [Total Orders],
    0
)


------------------------------------------------------------
8. Profit Margin
------------------------------------------------------------

Profit Margin =
DIVIDE(
    [Total Profit],
    [Total Sales],
    0
) * 100


------------------------------------------------------------
9. Average Sales
------------------------------------------------------------

Average Sales =
AVERAGE(SalesData[Total_Sales])


------------------------------------------------------------
10. Average Profit
------------------------------------------------------------

Average Profit =
AVERAGE(SalesData[Profit])


============================================================
STEP 4 — DATE TABLE
============================================================

Modeling → New Table


DateTable =
CALENDAR(
    MIN(SalesData[Order_Date]),
    MAX(SalesData[Order_Date])
)


Create these columns:


Year =
YEAR(DateTable[Date])


Month Number =
MONTH(DateTable[Date])


Month =
FORMAT(DateTable[Date], "MMMM")


Quarter =
"Q" & FORMAT(DateTable[Date], "Q")


Month Year =
FORMAT(DateTable[Date], "MMM YYYY")


Day =
DAY(DateTable[Date])


Day Name =
FORMAT(DateTable[Date], "DDDD")
